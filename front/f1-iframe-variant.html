F1 — embedded (integration) variant

This page embeds f1-poc.html in an iframe with allow="camera; microphone", which is how a video/call integration would be embedded. Open this page inside the Front desktop app: the inner page should get camera + mic with no prompt. Without the allow attribute Chromium blocks it, which is why that detail matters.

Note: when embedded, clipboard.readText() may still be refused by Chromium for cross-origin frames — camera/microphone are the decisive signal here.
